# 2026-08-31 正式增量更新公告

本次候选版本从上一正式基线 `e5adc20` 增量更新。发布只替换应用代码和静态资源，并按独立步骤导入招聘来源配置；不会复制 Labs 的岗位、采集快照、任务历史或其他测试数据。正式切换前必须完成数据库备份、迁移计划核对和健康检查。

## 用户可见更新

- 答题中心改为单题浏览、左侧题号导航、自动保存、提交后答案与解析并列查看；答题顺序按题型分组，题号状态和退出路径更清晰。
- 知识文档、题库和历史记录使用有界分页与局部刷新，管理端队列、审核、删除冷静期和通知状态更加可观察。
- 文章导入、Markdown/Tiptap 编辑、代码块和 LaTeX 块的编辑与预览链路得到修正；Markdown/HTML 渲染继续使用统一媒体安全策略。
- 找工作页面支持发布时间排序、分页多选筛选、岗位收藏视图和管理端按需加载；岗位名称、表头和操作区域保持稳定布局。
- 新增并修订 Hotjob、Feishu 和 Beisen 来源适配器，保留来源发布时间、分页闭合和安全域名白名单。

## 招聘来源处理

本次可随候选版本导入 `config/opportunity_sources.additions-2026-08-29.all.json` 中的 109 条增量来源（88 条启用、21 条停用），并保留既有 41 条来源。导入命令只写来源配置，会把新增来源置为未公开、未检查状态，不发起网络请求。不得在发布窗口手动调用来源检查；首次岗位采集由既有 Celery 定时任务按计划触发，失败或截断按现有通知和隐藏策略处理。

## 回退边界

应用健康失败时只恢复上一应用镜像，数据库保持前向迁移；不反向迁移、不删除岗位或媒体。任何备份、迁移、来源导入或健康读回失败都停止后续切换并保留现场证据。
