# Kaj 空间正式增量更新公告

发布时间：2026 年 8 月 31 日

本次更新已完成正式环境增量部署。更新基于上一正式版本前向发布，不清空既有账户、文章、媒体、岗位和答题数据；Web、Worker、Beat 已切换到同一候选版本，数据库结构无需新增迁移。

## 主要更新

### 答题中心

- 答题改为一次展示一道题，支持上一题、下一题和题号导航。
- 题号按单选、多选、判断、简答分组，作答状态、提交结果和解析状态更清晰。
- 答案会自动保存，刷新或暂时离开后可以继续未完成的试卷。
- 提交后可在右侧查看作答情况、正确答案和解析；简答题保留待复核状态。
- 题库配置、题库列表和历史记录继续使用局部刷新，减少整页闪烁和重复加载。

### 知识文档与题库生成

- 完善知识文档导入、审核、申诉、题库生成和删除冷静期的状态展示。
- 模型输出的结构校验和业务语义校验失败时，交由有界任务重试；失败调用不计入每日模型额度，并通过通知中心说明原因。
- 题库生成按文档中的细粒度知识单元自行判断知识点和题目数量，不再强制凑固定题数。
- 管理端批量处置、队列分页、生成历史和失败状态的反馈更加明确。

### 文章编辑与渲染

- Markdown 导入、富文本编辑、代码块和 LaTeX 块编辑链路得到修正。
- LaTeX 公式支持实时预览和正文渲染；KaTeX 字体资源已纳入正式静态资源，避免公式显示为缺失字体或裂图。
- Markdown、TipTap 和 HTML 继续使用统一的安全渲染策略。

### 找工作

- 岗位列表支持按企业发布时间排序，并以岗位名称作为次级排序依据。
- 岗位、来源、收藏和管理页面使用按需分页与多选筛选，降低一次性加载全部数据造成的卡顿。
- 新增并修订 Hotjob、Feishu 和 Beisen 来源适配器，保留发布时间、分页边界和安全域名限制。
- 新增 109 条来源配置，其中 88 条启用、21 条停用；停用来源不会出现在公开岗位列表中。

## 招聘来源采集说明

本次发布只导入来源配置，没有在发布窗口手动抓取新企业岗位，也没有把 Labs 的岗位数据复制到正式环境。新增来源初始为未公开、未检查状态，后续由现有 Celery 定时任务在计划窗口自动执行采集。

采集完成后，系统会按来源逐项记录成功、失败、截断和岗位数量；外部招聘网站结构变化导致的失败会通过管理员通知中心反馈，不会伪造岗位数量或把测试数据直接展示给用户。

## 稳定性修复

- 修复 PostgreSQL 连接中断后招聘检查留下失效运行状态的问题。
- 每分钟恢复任务现在会同时处理过期租约，以及“TaskRun 已终态但领域检查仍显示运行中”的历史孤儿运行。
- 本次发布前已收口正式环境中发现的历史孤儿检查；当前没有活动中的招聘检查、运行中来源或 running TaskRun。
- Web、Worker、Beat 均已通过健康检查，主页、文章、找工作、知识文档和答题入口正常访问。

## 数据与回退

本次正式部署前已创建并校验数据库 custom dump 与媒体归档，旧应用镜像继续保留。若后续发现应用健康问题，只回退应用镜像，不反向迁移数据库，也不删除现有岗位或媒体数据。

感谢你的持续测试和反馈。本次新增招聘来源会等待定时任务完成首次采集后，再逐步进入公开岗位展示和后续质量观察。
