# AGENT 知识文档与题库学习能力更新

本次为增量更新，覆盖从公开题库到登录答题、错题本、答题记录和清理恢复的完整链路。现有文章、账户、媒体和招聘数据不被重算；生产发布时只按迁移清单执行数据库前向迁移，不反向迁移。

## 面向用户

- 登录用户可从顶部进入答题，选择公开题库、题型、题量、随机设置和软计时。
- 作答答案自动保存，刷新或跨设备可恢复；并发编辑以版本冲突保护，网络失败保留当前输入。
- 提交后显示客观题结果和简答自评，不把自评伪装成自动分数。
- 错题本按题库分组，默认显示待复习题；掌握状态只由用户手动切换，答对不会自动隐藏。
- 答题记录支持筛选、详情、CSV 导出、单条/复选批量/清空删除，删除进入 7 天冷静期并可撤销。

## 安全与运维

- 通知继续复用统一 Outbox、消费幂等、Markdown sanitizer 和回执已读接口。
- 题库、文档、答题记录到期清理均为有界数据库事实；AGENT/学习 token 预留过期后保守恢复，磁盘容量仍由 operations owner 采样裁决。
- 账户终局删除会清理本人学习数据，并将其他用户历史中的作者快照固定匿名为“已注销用户”。
- 公开题库 API 仍默认关闭；真实 Provider 调用和生产数据动作不包含在本次代码增量中。
