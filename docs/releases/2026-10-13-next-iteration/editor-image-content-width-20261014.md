# 富文本图片 100% 宽度统一（2026-10-14）

## 用户可见变化

- 图片尺寸的四档均以编辑/阅读内容列的可用宽度为基准。`100%` 铺满可用列，`25%/50%/75%` 仍显示对应列宽比例，并保持图片自然宽高比。
- 页面宽度随桌面、平板和手机内容区域变化；不固定像素尺寸，也不修改媒体原始文件。

## 根因与实现

- 图片 schema 将默认宽度 `100` 规范化为省略字段；因此一部分默认宽度图片没有 `data-width`。
- 既有 CSS 只为带 `data-width` 的图片设置 `width: 100%`。没有该属性时浏览器使用图片自然尺寸，造成 100% 与另外三档含义不一致。
- `static/src/editor-image.css` 将 100% 基础宽度应用于编辑器与公开文章中的所有图片；25/50/75 规则继续按显式 `data-width` 覆盖。没有新增像素、style 或其他持久化属性。
- `templates/base.html` 更新 CSS 查询版本，确保浏览器获取新样式。
