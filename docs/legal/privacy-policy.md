# 隐私政策

**生效日期：2026 年 8 月 27 日**

Kaj 的小房间（网站地址：`kajspace.cn`，以下简称“本站”）由个人开发者 Kaj 运营。本政策说明本站如何收集、使用、保存、共享和保护与个人有关的信息，以及你可以如何行使相关权利。

## 一、适用范围

本政策适用于本站提供的账户、文章阅读与发布、评论和留言、点赞、收藏、阅读书签、通知、招聘信息聚合、附件、知识文档、题库和相关页面与接口。跳转到招聘单位、Bilibili、AI 服务商或其他第三方网站后，适用第三方自己的隐私规则。

## 二、我们处理哪些信息

### 1. 账户与认证信息

注册或登录时，本站会处理邮箱地址、你设置的用户名或昵称、密码的安全哈希、邮箱验证码流程所需的短期状态，以及账户状态、角色和权限。密码、验证码和会话原始令牌不会以可直接登录的形式保存。

你可以在个人设置中提供头像、主题和其他资料。头像文件会按照媒体安全规则处理，并与对应账户绑定。

### 2. 你主动提交的内容和操作记录

本站会保存你主动创建或提交的文章、文章修订、摘要、评论、留言、评论举报、标签申请、点赞、岗位收藏、文章收藏、阅读书签、通知和答题记录。文章的可见范围由作者选择；公开、登录可见和私人内容不会因为本政策而改变。

如果你使用知识文档和题库功能，本站会保存你上传的知识文档、题库配置、生成状态、题目、错题和答题记录。该功能需要相应的登录、作者或附件权限。

### 3. 图片、附件和其他上传内容

本站可能接收头像、文章封面、正文图片、评论图片、文章附件、导入文件和知识文档。文件会进行格式、大小、编码、真实类型、恶意内容和图片元数据检查，并存储在受控媒体目录中。未完成安全处理或未绑定到业务对象的临时文件会按清理规则处理。

文章附件仅接受 ZIP、7z、RAR、MD 和 TXT，单个附件不超过 10 MiB；知识文档使用独立的 Markdown 规则。具体限制以页面当前提示和服务端校验为准。

### 4. 安全、审计和运行信息

为了防止滥用、处理登录限制、维护服务和调查安全事件，本站可能记录请求时间、客户端 IP 地址、浏览器或设备摘要、请求结果、错误码、操作审计和安全关联编号。评论的客户端 IP 可能作为评论安全事实长期保存，完整 IP 只提供给有权限的管理员查看。

本站不会在普通日志、通知或审计摘要中保存密码、验证码、Cookie、API 密钥、连接串、文章正文或原始上传内容。

### 5. 访问统计

正式环境使用本站自托管的 Umami 进行匿名化访问统计。统计可能包含访问时间、页面路径、来源页面、设备或浏览器类型等技术信息，用于了解页面使用情况和改进服务，不用于出售个人画像或投放广告。Umami 数据按不超过一个月的周期清理。

### 6. 招聘信息

工作机会页面中的岗位、企业、城市、届别、类别、发布时间和官方链接来自公开招聘来源。本站处理这些公开信息是为了整理和展示工作机会，不以此推断你的求职意向，也不会把你的账户信息提供给招聘来源。岗位申请应在对应官方页面完成。

## 三、我们为什么使用这些信息

本站按照以下目的处理信息：

- 创建和维护账户，完成邮箱验证、登录、会话管理和账户安全；
- 提供文章、评论、留言、收藏、点赞、阅读书签、通知和答题功能；
- 按你选择的可见范围展示内容，并执行内容审核、举报处理和反滥用措施；
- 处理图片、附件和知识文档，完成必要的安全检查、格式转换和媒体存储；
- 在你主动发起知识文档整理或题库生成时，执行相应的 AI 处理任务；
- 统计和诊断服务运行情况，改进页面、性能和安全；
- 履行法律义务、处理争议、保护本站和用户的合法权益。

提供账户邮箱是完成账户认证和发送必要通知的前提。其他内容通常由你自行决定是否提交；未提交时，对应功能可能无法使用。

## 四、Cookie、本地存储与类似技术

本站使用必要的会话和安全 Cookie，以维持登录状态、防止跨站请求伪造、记录评论回执和完成基本功能。登录会话 Cookie 使用安全属性，服务端只保存会话令牌摘要。

本站还可能在你的浏览器本地保存主题选择、岗位列表显示列、评论排序和编辑恢复所需的临时状态。这些数据用于记住你的界面偏好，不会作为账户资料上传到服务器。你可以通过浏览器设置清除它们，但清除后部分偏好和本地草稿恢复能力会丢失。

本站不使用广告 Cookie，不出售跨站跟踪数据。Umami 的统计脚本仅在正式环境配置完整时加载。

## 五、共享、委托处理与第三方服务

本站不会出售、出租或交换你的个人信息。只有在提供服务、履行法律义务或保护安全所必需的范围内，才会进行以下处理：

1. **服务器、数据库和缓存**：账户、内容、权限和业务记录存储在本站运营者控制或管理的服务器、PostgreSQL 和 Redis 环境中；Umami 使用独立的统计数据库。
2. **邮件服务**：邮箱验证码和必要的运维通知通过本站配置的 SMTP 服务发送。邮件服务商会接收完成投递所需的邮箱、主题和邮件内容。
3. **AI 服务 Endpoint**：只有在你主动使用知识文档整理或题库生成功能时，所选文档的必要内容才会发送到管理员配置的模型 Endpoint。Endpoint 可能由 OpenAI、Anthropic、DeepSeek 或兼容接口提供。本站不在普通页面展示 API 密钥；第三方是否保存输入和输出，以其服务条款和隐私政策为准。
4. **媒体与嵌入服务**：查看受信任的 Bilibili 内容时，浏览器会直接请求 Bilibili；该请求受 Bilibili 的规则约束。本站只对已配置并允许的来源提供嵌入。
5. **招聘和外部链接**：点击岗位官方链接或其他外链后，你会离开本站，第三方可能按自己的规则处理访问信息。

本站不会为了广告画像向上述服务提供你的完整账户资料。涉及必要的服务商变更、跨境传输或处理目的变化时，本站会更新本政策并在需要时依法取得你的授权。

## 六、保存期限与删除

本站只在实现本政策目的所需期间保存信息，并遵守以下生命周期：

- 邮箱验证码一般在 10 分钟后失效，发送限制和短期认证状态由短期存储维护；
- 账户在使用期间保存。账户删除后，必要的审计、安全记录和删除身份快照可能继续保留，但不会保留可登录的凭据；
- 文章删除设有 7 天恢复期，期满后正文、修订、媒体和评论按删除流程清理；
- 导出文件最多保留 3 天，数据库和媒体备份最多保留 30 天；
- 招聘检查历史按约 90 天到期清理，岗位和必要的业务历史可能继续保留；
- 通知、审计和安全错误记录按业务与安全需要保留，用户界面会排除已隐藏或删除的通知；
- 知识文档和答题记录按其删除、恢复和清理规则处理，必要的状态和审计事实可能继续保留；
- 无法与账户或业务对象关联的临时上传文件，会在清理任务中删除。

法律规定的保存期限、争议处理或安全事件调查需要继续保存时，本站会在必要范围内延长保存，并在目的消失后删除或匿名化。
