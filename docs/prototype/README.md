# Kaj的小房间前端原型清单

原型目录：`index.html`

图片目录：`images/`

视觉系统：中性浅灰底、白色工作面、细线网格、深酒红操作强调、淡杏媒体占位、现代无衬线字体。所有页面使用同一信息层级和最大 6px 圆角。

## 交互方式

- 顶部“界面原型目录”下拉框可进入每个独立功能界面。
- 公共导航、侧栏、文章索引行和主题色可直接点击；主题支持亮色、暗色和护眼模式。
- 发布、删除、隐藏、举报、申诉、注册、密码重置、会话退出、禁用、封禁 IP、邀请码、标签审核、导出与保存设置均会弹出对应确认窗口。
- 弹窗确认后会在浏览器内存中更新假数据状态并显示操作反馈；刷新页面即重置。这些操作不会连接或修改真实服务器数据。

## 原型审查范围

1. 检查每个模块的美术风格、层级、留白、边框、颜色与文字密度是否一致。
2. 检查各类身份的操作是否被放在正确入口：访客、注册用户、作者、管理员。
3. 检查移动端是否仍能连续完成搜索、阅读、编辑、管理和运维查看。
4. 确认后，原型目录、页面间导航和关键控件会成为架构设计文档中的前端输入。

## 施工边界

本原型包含 17 个复合视图和 21 张参考截图，主要冻结视觉语言、信息密度和页面组合方式；它不覆盖全部生产路由，也不证明后端、权限、异步或持久化行为。

正式实现必须先读取 `page-state-matrix.md` 和 `../architecture/contracts/03-frontend-contract-map.md`。矩阵覆盖 42 个路由、四类身份、S0-S7 状态以及 390/768/1440 视口；矩阵和架构契约优先于本文件中的演示交互。

已知原型收口项：访客/登录 Header 变体、个人通知入口、手机编辑/预览切换、弹窗焦点与 Escape、暗色语义 token、管理页 768px/手机导航和异常状态均由实现阶段按矩阵完成，不得把当前截图中的缺失或假数据当产品要求。
