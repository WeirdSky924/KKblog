# 模块验证与验收矩阵

完成一项功能需要选择能证明其承诺的最高证据层。`static` 不能替代数据库读回，mock 不能替代真实容器，页面存在不能替代完整用户流。

## 分层证据

| 层 | 工具/环境 | 证明内容 |
| --- | --- | --- |
| Static | Ruff、Django checks、模板/链接检查 | 语法、import、配置、静态结构 |
| Logic | pytest unit/service/policy | 规则、状态迁移、错误码、幂等 |
| Data | 测试 PostgreSQL + 临时媒体目录 | 约束、事务、锁、写入读回、迁移 |
| Flow | Playwright + 真实 Django/worker | 点击、请求、权限、异步完成、UI 读回 |
| Operational | Compose/health/backup/deploy sandbox | 服务就绪、进程、告警、失败与回退 |

## 高风险权限场景

以下场景必须使用参数化服务测试和浏览器直接 URL 两种证据：

1. 访客打开登录文章看到提醒页并登录回跳。
2. 普通用户/其他作者打开私人、草稿、软删除文章得到相同 404。
3. 管理员查看他人私人/草稿成功，作者同日只收到一次通知。
4. 管理员不能编辑、发布、排期或改他人文章设置，即使伪造 POST。
5. 管理员只能隐藏已发布文章；作者不能自行解除管理员隐藏。
6. 禁用作者后发布文章消失、定时转草稿；启用后仅前者自动恢复。
7. 被 IP 封禁的已登录用户只能作为访客浏览大众内容。
8. 举报结果与通知不泄露举报人身份。
9. 无附件能力账户不能上传/审核/生成，但仍可登录答题；管理员不能代替他人生成题库。
10. 知识原文仅 owner/管理员可见，管理员成功读取可追溯；公开 HTML/API 永不泄露原文或 Prompt。
11. API 关闭时任意详情 ID 与列表在对象查询前返回同一 `404/api_disabled`；Redis 限流故障在 query 前 fail closed。

## 数据与并发场景

- 两个注册请求消费同一邀请码，只有一个成功。
- 两个保存请求用同一 row version，只有一个创建新工作修订。
- 两个 Worker 领取同一定时文章/评论，只发生一次状态转换。
- 标签删除和文章保存并发，不产生超过十标签或幽灵关联。
- 导出同时请求，数据库只允许一个 RUNNING。
- 导出完成与取消竞态只能得到 Completed 或 Cancelled 一个终态。
- 数据库提交后文件删除失败，页面不可再访问文件，重试后清理成功。
- Outbox 重复投递不重复通知、审计或清理。
- 两个模型 Worker 领取同一 review/generation run，只产生一次 invocation、一次额度预留和一个业务终态。
- token reset 与活跃 reservation 并发时不释放在途额度；可信/缺失 usage 重复结算均对账一致。
- 题库修订/隐藏/删除与答题提交并发时，attempt 继续使用固定 revision/快照且新公开读取及时失效。

## 页面视觉状态

每个用户可见页面至少检查：

- 1440px 桌面和 390px 手机完整视口，无横向溢出或操作遮挡。
- 加载、空、字段错误、系统错误、禁用、无权、成功和恢复态。
- 弹窗焦点锁、Escape、确认对象、重复提交禁用和关闭后焦点返回。
- 亮色、暗色、护眼 token；文本对比、焦点环、44px 左右触控目标。
- 长标题/昵称/错误文案、20/50 条列表、深层评论和管理表格溢出。

## 上线前手工验收

1. 用访客、普通用户、作者、管理员四种身份跑完整导航。
2. 创建 Markdown 与 TipTap 文章，上传图片，发布、编辑、重发、恢复版本。
3. 测试三种可见性、登录回跳、搜索/标签/分区/sitemap。
4. 评论缓冲 10 分钟、回复、删除、举报、申诉、管理员终局。
5. 注册开关、邀请码、验证码、登录限制、设备会话和 IP 封禁。
6. 管理员查看/隐藏/删除他人文章并核对通知和审计。
7. 导入混合成功包，导出私人/历史内容，取消一次导出并验证下载授权。
8. 触发可控任务失败，核对三次重试、错误码、站内和邮件告警。
9. 创建一次数据库+媒体备份并核对记录；不宣称已恢复验证。
10. 在获授权的部署演练中核对维护页、健康检查和应用回滚。
