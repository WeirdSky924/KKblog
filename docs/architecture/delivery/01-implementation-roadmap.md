# 可执行实施路线

本路线只描述领域能力之间的交付关系，不是实施阶段、任务状态或 13 个一次性 Goal 的编号。精确、无反向依赖的阶段顺序只以 `docs/planning/implementation-todolist.md`、`implementation-readiness.md` 和分阶段 Todo 为准。首版完整功能统一部署；下列能力簇必须在其所属 Todo 阶段内闭环并通过门禁。

## 能力簇 0：项目与质量骨架

交付：uv/Python 3.12、Django settings 分层、Compose 内网、PostgreSQL/Redis/Mailpit/Celery/Caddy、错误码/trace、健康检查、pytest/Ruff/Playwright、静态资源构建。

退出条件：缺少必需 `.env` 明确失败；容器健康有真实请求；普通 500 只显示通用错误码；基础模板在 1440/390 可用。

## 能力簇 1：账户事实与安全入口

依次闭环：自定义 Account/角色 → 会话 → 验证码端口和 Mailpit → 注册开关/邀请码 → 双登录 → 密码/邮箱变更 → 登录限制/IP 封禁 → 管理员初始化。

先实现策略和服务，再接注册/登录/个人/管理页面。退出条件包括并发消费邀请码、第五次码失败、每日 20 次、五次登录限制、会话轮换、唯一管理员与首次改密。

## 能力簇 2：媒体基础

交付 staging、真实格式解码、2 MiB、`DEC-005` 静态/动图解码上限、EXIF、GIF、storage key、Binding、授权读取、幂等清理和磁盘门禁。先用头像/Logo 做小消费者验证，再供文章和评论复用。

退出条件：伪 MIME、路径穿越、超限、删除失败重试、私人资产越权和临时文件清理均有测试。

## 能力簇 3：文章修订核心

交付 Article/Revision、Markdown/TipTap source、工作/发布指针、版本令牌、云草稿、发布预览、立即/定时、旧发布版本读取、历史恢复、软删除。

暂不做搜索/评论，但必须用真实数据库证明“编辑已发布文章不改变读者版本”和“冲突不覆盖”。

## 能力簇 4：分类、安全渲染与发现

交付 Section/Tag 审核、统一 sanitizer、可信 Bilibili、首页/分区/标签/标题搜索、目录 H2、SEO/sitemap、浏览量、收藏、主题和公开主页。

退出条件：PUBLIC/AUTH/PRIVATE 直接 URL、404 隐私、缓存失效、五标签排序、失效收藏和外链安全浏览器流。

## 能力簇 5：评论与留言板

交付 DiscussionThread、10 分钟缓冲、访客/用户冷却、树回复、分页/展开、图片、删除占位、作者管理、留言板复用。

退出条件：关闭评论只阻止新建；删除节点保留子回复；两个 worker 不重复公开；访客不能回复/举报。

## 能力簇 6：审核与通知

交付举报、一次申诉、终局复审、管理员直接删除、文章隐藏/删除申诉、通知/回执/浮层/群发、查看与导出按日聚合。

退出条件：举报人隐私、初审删除后申诉恢复策略、通知去重、群发已读名单、管理员例外与审计。

## 能力簇 7：完整作者与管理界面

交付编辑器本地草稿、移动端预览、版本时间线、评论管理 tabs，以及用户/IP、文章、标签、分区、邀请码、导航、品牌、静态页、友情链接、设置、日志和任务页面。

该能力簇不新增第二套业务逻辑；管理表单只委托前面已测试的领域命令。

## 能力簇 8：导入导出与运维

交付安全解包、预览/逐项选择/部分成功、格式例外、单全局导出、受保护下载、三天清理、周备份、30 天保留、磁盘保护、Umami 一月清理、告警。

退出条件：zip-slip/zip bomb、外部作者 ID、幂等确认、导出取消竞态、最终失败通知和真实备份命令状态。

## 能力簇 9：跨模块回归与部署准备

执行完整权限矩阵、迁移读回、任务并发、桌面/手机用户流、无障碍、缓存、磁盘阈值、错误脱敏和备份。准备 `.env.example`、Caddy 域名占位、维护页、部署/应用回滚脚本。

未得到用户明确部署授权前只验证脚本的隔离/模拟路径，不迁移生产、不重启服务、不切换运行版本。

## 每个能力簇的固定节奏

1. 从需求/状态机写行为测试，确认 RED 原因正确。
2. 建 schema/约束与迁移测试。
3. 实现 policy/query/service，不接页面也能数据库读回。
4. 接 View/form/template/HTMX，复用展示 DTO。
5. 补 outbox/task/通知/审计和失败路径。
6. 跑聚焦 pytest、相关回归、Ruff。
7. 用 Playwright 执行真实身份/动作/读回，检查 1440 与 390。
8. 对照模块验收表，记录命令、退出码和未验证项。

## 变更大小门禁

- 新行为先确认唯一所有者；不存在才新建模块。
- View 不开启跨聚合事务；Service 不返回 HttpResponse；Task 不复制 Service。
- 文件接近 800 行评审职责，超过 1,200 行新增行为前拆分。
- 迁移、权限、公开契约和跨域事件变更按高风险评审。
- 不因“以后也许需要”创建公共 API、抽象 Repository 基类或万能 EventBus。
