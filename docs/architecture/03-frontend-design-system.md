# 前端与美术设计架构

## 原型到实现

`docs/prototype/index.html` 是复合信息架构和视觉方向基线；42 个生产路由、身份、S0-S7 状态和视口以 `docs/prototype/page-state-matrix.md` 为施工补充。正式实现使用 Django 基础模板、领域模板、HTMX 片段和少量 Alpine 状态；不引入第二个 SPA、客户端路由器或通用前端数据仓库。

## 视觉气质

方向是瑞士编辑式阅读界面：中性留白、细线网格、清晰索引、深酒红操作强调和淡杏媒体表面。它应安静、克制、适合长文和反复管理，不做营销 Hero、装饰性渐变、光斑、悬浮大卡片或夸张圆角。

视觉判断优先级：信息层级 > 阅读舒适度 > 操作可发现性 > 装饰。状态差异不能只靠颜色表达。

```css
:root {
  --surface-page: #F7F7F8;
  --surface-panel: #FFFFFF;
  --surface-muted: #F1F1F2;
  --surface-media: #F4D9C8;
  --text-primary: #202124;
  --text-secondary: #65676B;
  --line: #D9D9DC;
  --accent: #7E2637;
  --accent-hover: #681E2D;
  --danger: #A12635;
  --success: #2F6B4F;
  --warning: #8A5A17;
  --focus: #1F67A5;

```

- 暗色：页面 `#171719`、工作面 `#202024`、主文字 `#F2F2F3`、线 `#3A3A40`、强调 `#D46A7E`、媒体 `#4B3330`。
- 护眼：页面 `#EEF1E8`、工作面 `#F8FAF3`、主文字 `#26302B`、线 `#CCD2C6`、强调 `#7A3440`、媒体 `#E9D5C2`。
- 三主题只替换语义 token，不在组件里散落十六进制颜色。
- 破坏、成功、警告使用独立语义色，避免全站只剩酒红单一色相。

## 字体与排版

- 字体栈：`Inter, "Noto Sans SC", "Microsoft YaHei", system-ui, sans-serif`；正文、标题和品牌同族。
- 正文 16px/1.75；长文桌面最大 720px 行宽，中文每行约 35-42 字。
- 页面 H1 28px/1.35，H2 22px/1.45，面板标题 18px/1.4，说明/元数据 13-14px。
- 导航和按钮 14px；不随视口连续缩放字号；letter-spacing 固定 0。
- 标题最长 30 字，列表中最多两行后省略；详情页完整换行，不遮挡元数据。

## 空间与结构

- 4px 基础间距：`4/8/12/16/24/32/48/64`；同组 8-12，组间 24-32。
- 页面内容最大 1280px，左右安全边距桌面 32px、平板 24px、手机 16px。
- 圆角仅 `0/4/6px`；1px 边框；普通页面不使用浮动阴影卡片。
- 单项卡片只用于文章索引、评论、通知等重复对象；页面分区保持无框/full-width，不在卡片中再嵌套卡片。
- 固定工具栏、按钮、头像、标签控件使用稳定尺寸，动态文字不引起布局跳动。

## 页面骨架

```text
base.html
  site_header
    brand/logo + theme
    notification popover
    auth links or avatar/personal menu
  global_feedback_region
  page_header (optional, compact)
  main
    home_sidebar (admin-managed navigation, home only)
    page-specific layout
  site_footer
  modal_layer
```

首页以本地品牌默认封面构成全宽首屏，封面下进入连续文章目录，不使用卡片墙。顶部栏在首页滚动期间保持粘性可见。图片区向下滚动一次直接吸附到顶部栏下方的文章区域顶部；文章区域顶部向上滚动一次直接回到顶部栏下方的图片顶部，文章区域内部仍保持普通连续滚动。管理员配置的导航树固定为左侧浮层：桌面在首屏默认收起，文章目录进入视口后自动展开，用户仍可随时手动收起或展开；正文始终位于左右对称预留导航宽度的中栏，不随浮层状态移动。移动端默认收起，展开后作为有界抽屉覆盖页面，不自动遮挡文章。`Escape` 可收起并恢复焦点。顶部栏不渲染这棵导航树。文章分区作为导航树节点与站内页、外链统一排版，首页不再额外渲染固定分区入口；点击分区节点在同一主页文章区域内更新分区名、文章列表和分页，刷新分区 URL 时仍保留完整主页结构。其他公共阅读页桌面可用 8/4 或 9/3 栅格，文章正文与目录并列；手机顺序为正文、目录折叠入口、评论。管理页桌面是窄模块侧栏 + 主工作区；手机侧栏变为顶部横向模块导航，不遮挡表格和主操作。

## 组件规范

| 组件 | 规范 |
| --- | --- |
| Button | primary 酒红、secondary 边框、danger 独立危险色；pending 固定宽高并禁重复提交 |
| Icon button | 使用 Lucide 熟悉图标，32/36/40px 稳定方形；陌生图标有 tooltip 和 aria-label |
| Input | 标签常驻；错误紧邻字段；不能只靠 placeholder 表意 |
| Tabs | 登录方式、管理视图等同级模式；键盘方向键可切换 |
| Segmented control | 编辑/预览、主题等少量互斥即时模式 |
| Tag chip | 只用于真实标签/状态，不把普通命令做成文字胶囊 |
| Table/list | 表头稳定；手机优先重排关键字段，操作进入 overflow menu |
| Modal | 显示目标、影响、原因/证据；焦点锁、Escape、关闭返回触发点 |
| Toast | 短期结果反馈；字段错误不放 toast；后台任务接受不显示完成 |
| Empty state | 一句对象状态 + 一个可用主动作，不写功能说明书 |
| Skeleton | 只匹配稳定内容骨架，不用旋转大图标造成布局变化 |

## 文章索引

稳定网格为封面、内容、元数据/动作三块。显示封面、标题、摘要、分区、最多必要标签、发布时间、浏览量和评论数；不显示无数据的空标签。仓库自有 `1600x900` 默认封面和 `800x450` 失效收藏图有不同语义，不得混用。标签筛选最多五个，溢出时换行而不横向挤压标题。

## 阅读页

文章名称是首屏主要信号，封面展示真实上传/默认图，不做暗化背景 Hero。自动目录只收 H2；桌面粘性侧栏，手机为可展开导航。外链有新标签图标/语义，分享是复制链接按钮。评论区与正文用线和间距分组，不放在正文卡片内部。

## 编辑器

- 桌面：编辑与预览等宽或 5/5，工具栏和发布动作稳定，不因预览变化移位。
- 手机：使用编辑/预览 segmented control；发布/保存在可达工具栏，键盘弹出不遮挡。
- Markdown 与 TipTap 共用标题、摘要、封面、分类、可见性、评论设置、媒体选择和终稿审查；编辑器内核独立。
- 编辑器接收剪贴板中的本地图片文件并复用正文图片上传链路；上传期间在原粘贴位置显示临时状态，成功后原位替换为 `media:` 引用，普通文本粘贴保持浏览器原生行为。
- 同一批图片按剪贴板顺序上传和插入。上传未结束时阻止云端保存、Markdown 覆盖导入和离页；临时引用不得进入本地稿或 TipTap 保存 JSON。
- 撤销临时粘贴位置不删除已经上传的媒体，资源保留在正文图片库供再次插入；失败时移除临时状态并通过全局反馈说明重新粘贴重试。
- 本地已保存、云草稿进行中、冲突、磁盘限制和保存失败使用明确状态，不把自动保存写成虚假成功。

## HTMX 与 Alpine 边界

- HTMX：搜索、筛选、传统分页、评论无限加载、管理列表、通知已读、导入预览和局部表单结果。
- Alpine：弹窗开关、主题即时切换、编辑器局部显示、文件选择预览和无服务端依赖的微交互。
- 服务端渲染是事实来源；partial 不定义隐式外部 JSON API。错误/冲突协议见 `contracts/03-frontend-contract-map.md`。

## 响应式与无障碍

- 主要断点按内容需要确定，至少验证 390、768、1024、1440；不是只把桌面缩小。
- 页面级滚动唯一；弹窗内部只有内容超高时局部滚动；固定层不得遮挡主操作。
- 键盘可达、焦点清晰、对比度满足 WCAG AA 的常用文本要求，支持浏览器缩放和 `prefers-reduced-motion`。
- 触控目标建议最小 44px；横向表格必须提供重排或受控滚动，并保留当前对象上下文。
- 模态捕获焦点、Escape 关闭（破坏性提交进行中除外）、关闭后返回触发点。

## 视觉验收

每个页面在 1440px 和 390px 做真实浏览器操作与完整视口截图；管理密集页面再检查 768px。至少检查默认、展开/弹窗、空、字段错误、系统错误、禁用和成功状态。三主题抽样覆盖 Header、阅读页、表单、管理表格、弹窗和语义状态色。

视觉截图只能证明布局；保存、权限、异步和数据库行为必须按 `delivery/02-module-verification-matrix.md` 读回。
