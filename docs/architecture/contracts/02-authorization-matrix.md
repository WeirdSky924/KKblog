# 服务端授权矩阵

符号：`Y` 允许，`N` 禁止，`Own` 仅本人对象，`Policy` 还需满足对象状态/设置。作者列指对象作者；“其他作者”是已具作者角色但不拥有该对象。

## 文章读取

| 对象 | 访客 | 普通用户 | 作者本人 | 其他作者 | 管理员 |
| --- | --- | --- | --- | --- | --- |
| 大众已发布 | Y | Y | Y | Y | Y |
| 登录已发布 | 登录提醒 | Y | Y | Y | Y |
| 私人已发布 | 404 | 404 | Y | 404 | Y + 通知作者 |
| 草稿/工作修订 | 404 | 404 | Y | 404 | Y + 通知作者 |
| 未到时定时文章 | 404 | 404 | Y | 404 | Y + 通知作者 |
| 软删除冷静期 | 404 | 404 | Y | 404 | Y + 通知作者 |
| 管理员隐藏 | 404 | 404 | Y（仅查看/申诉） | 404 | Y |
| 作者禁用遮罩 | 404 | 404 | 登录被禁用 | 404 | Y + 通知作者 |
| 永久删除 | 404 | 404 | 404 | 404 | 仅审计/案件记录 |

管理员查看他人文章的通知按作者、文章、上海自然日去重，每天最多一条。此处采用后续确认的管理员例外，覆盖访谈中较早的“草稿仅作者可见”表述。

## 文章命令

| 动作 | 普通用户 | 作者本人 | 其他作者 | 管理员对自己 | 管理员对他人 |
| --- | --- | --- | --- | --- | --- |
| 新建文章 | N | Y | N | Y | N |
| 保存/编辑/设置 | N | Y | N | Y | N |
| 上传/更换单个附件 | N | Policy：需独立附件能力 | N | Policy：需独立附件能力 | N |
| 发布/重发/排期 | N | Y | N | Y | N |
| 改可见性 | N | Y | N | Y | N |
| 恢复历史修订 | N | Y | N | Y | N |
| 软删除 | N | Y | N | Y | Y + 通知/审计 |
| 7 天内恢复 | N | Y | N | Y | Y + 通知/审计 |
| 隐藏已发布文章 | N | N | N | 可作为管理员 | Y + 通知/审计 |
| 恢复管理员隐藏 | N | N | N | 可作为管理员 | Y + 通知/审计 |
| 转移作者 | N | N | N | N | N |
| 导出 | N | N | N | 仅管理员入口 | Y + 通知受影响作者 |

管理员与作者是同一账户时，处理自己的文章应显示当前使用的角色语义；普通作者命令不产生“管理员操作他人内容”通知。所有管理员写命令仍审计。

附件能力只控制新附件上传和更换。能力撤销后，作者保存其他文章字段时可保留工作修订已绑定的附件；不得借此把历史附件或其他文章附件换入当前修订。撤销作者角色会在同一事务内撤销附件能力。

## 策略组合

最终授权不是单一角色判断：

```text
allow = network_policy
    AND authenticated_actor_policy
    AND role_policy
    AND object_ownership_or_admin_exception
    AND lifecycle_policy
    AND capacity_policy
    AND rate_limit_policy
```

读取需要存在性隐私时，把“对象存在但不可见”映射为 404；写入已知对象则使用明确禁止/冲突错误。模板可依据同一策略返回的 capability flags 决定按钮，但服务必须重新裁决，不能信任前端 flags。
