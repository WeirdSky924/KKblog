# ADR-005：唯一管理员的内容查看例外

状态：Accepted

## Context

私人文章原则上只限作者，但后续需求明确唯一管理员可查看任何作者的私人、草稿、定时和未发布修订，用于管理。管理员又不能替作者编辑或发布，且查看行为必须通知作者。

## Decision

建立显式 `AdminContentAccessPolicy`：唯一管理员可只读查看所有文章状态；查看他人文章按“作者 + 文章 + 上海日期”至多产生一条通知。管理员对他人内容只可隐藏已发布文章、删除/恢复，不能编辑、改设置、发布、重发、排期或转移所有权。

模板、完整页、HTMX 和服务统一调用该策略。普通不可见读取返回 404；管理员入口仍需要身份、唯一角色和对象状态检查。

## Consequences

- 管理能力与作者隐私之间的例外被集中、可测试、可追踪。
- 管理员查看不是传统写审计，但有永久事件/通知投递记录。
- 双角色账户操作自己的文章时走作者语义，不产生“查看他人”通知。
- 任何新增管理功能默认不得扩大此例外，必须更新 ADR 和权限矩阵。

## Superseded requirement wording

本决策采用后确认的管理员例外，覆盖较早“草稿仅作者可见、管理员不能查看”的表述；不改变普通用户和其他作者的禁止规则。

## Revisit when

系统允许多个管理员、引入审阅员角色或需要更严格的私密日志隔离时，必须重新设计双人授权/理由/只读水印等控制。
