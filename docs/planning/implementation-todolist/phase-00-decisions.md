### DEC-003 锁定昵称 Unicode casefold 唯一口径
- 元数据：状态 `完成`；阶段 P0；owner `accounts`；优先级 P0。
- 目标/行为：昵称以 Unicode `casefold` 规范值执行大小写不敏感唯一，因此 `Kaj` 与 `kaj` 冲突；展示值保留用户输入的原始大小写。
- 来源：访谈 Q097-Q100、Q295；`data/02-identity-content-fields.md` Account；`reference/01-requirements-resolution.md` §已确认 P0 决策；2026-07-21 用户批准基线。
- 依赖：前置无；后续 `ACC-001`、`ACC-007`、`QA-006`。
- 文件：未来账户模型、规范化函数、唯一索引、表单与迁移。
- 边界：只决定昵称；邮箱始终大小写不敏感；不改变中英文 16 单位预算和 7 天冷却。
- 影响：数据：唯一索引；权限/审计/缓存/异步/媒体/通知无。
- 测试/验收：参数化中英混合、大小写变体、casefold 冲突、删除后复用与并发提交；数据库规范值唯一约束最终裁决，UI 保留原展示值并对冲突给字段错误。
- 风险/停止：规范化仅在表单层、并发可写入重复、casefold 算法不一致或展示值被改写时停止账户 migration。
- 证据：2026-07-21 复核确认消歧表、Account 字段字典、账户模块不变量、`ACC-001`/`ACC-007` 测试门禁均使用同一 Unicode `casefold` 规范值并保留展示值；未发现口径漂移。当前无账户 schema 或隔离 PostgreSQL 可读回，数据库唯一约束与并发裁决留待 P3/P4；依赖审计退出 0，三个后续 ID 双向互认。
- 授权：`是`；属于用户可观察身份规则。

### DEC-005 确认默认视觉资产与安全阈值的工程默认值
- 元数据：状态 `完成`；阶段 P0；owner `media`；优先级 P1。
- 目标/行为：使用仓库自有 `1600x900` 默认封面和 `800x450` 失效图；静态图最长边 `8192` 且总像素不超 `25 MP`，动图不超 `200` 帧且累计解码不超 `100 MP`；导入包不超 `64 MiB` 压缩大小、`256 MiB` 展开大小、`1000` 项、`8` 层嵌套和 `100:1` 压缩比；正文默认 `2 MiB`，可配范围 `64 KiB` 至 `2 MiB`。
- 来源：访谈 Q038-Q045、Q075、Q095、Q161-Q165、Q230、Q276-Q280、Q314；`modules/04-media-rendering.md`；`flows/04-import-export-sequences.md` §导入包安全；`reference/01-requirements-resolution.md` §已确认 P0 决策；2026-07-21 用户批准基线。
- 依赖：前置无；后续 `MED-002`、`MED-005`、`CNT-002`、`DSC-006`、`EXC-001`、`ADM-007`、`QA-006`。
- 文件：未来 `static/brand/`、媒体校验配置、exchange 限额配置、站点设置。
- 边界：本决策不表示素材已制作或入库；不放宽全局单图 2 MiB；不下载许可不明素材；后续只能收紧安全上限，任何放宽需新决策；安全阈值不得通过前端绕过。
- 影响：数据：配置；媒体：默认资产/上传；权限：容量门禁；其余无直接变化。
- 测试/验收：对每个阈值做边界值与超限 RED；默认图在三主题、1440/390 清晰且不误作原文章封面；设置服务端拒绝超出 `64 KiB` 至 `2 MiB` 的正文上限。
- 风险/停止：资产版权不明、像素炸弹或 ZIP bomb 防护无法证明时停止对应上传/导入入口。
- 证据：2026-07-21 漂移探针退出 1，定位到本卡仍待确认、媒体/导入/正文来源缺精确数值且默认资产没有正确 owner 门禁；已按消歧表更新来源与下游任务卡，将资产交付门禁从无关的 `MED-007` 收敛到拥有 `brand assets` 的 `MED-005`。当前没有素材、上传器、导入器或正文配置可运行读回，本阶段未制作素材；修正后依赖/owner 审计退出 0。
- 授权：`是`（视觉/体验阈值确认）；安全下限可由工程进一步收紧并记录。
