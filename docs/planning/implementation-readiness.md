# 实施就绪与阶段执行契约

状态：13 个一次性阶段 Goal 的强制前置契约。Todo 定义做什么，本文件定义一个阶段何时可以开始、如何证明结束。

## 真值优先级

1. 用户当前回合的明确要求和授权。
2. 最新需求决策与 `architecture/reference/01-requirements-resolution.md`。
3. 架构 owner、数据、流程、权限、服务、事件和任务契约。
4. 本 Todo 任务卡及本文件的阶段门禁。
5. `prototype/page-state-matrix.md`。
6. 原型视觉截图。
7. 原型 HTML 的演示代码和内存假状态。

低优先级材料与高优先级冲突时不得自行折中；记录来源、影响和建议，回到决策或架构文档修正。

## Definition of Ready

启动一个阶段 Goal 前必须全部满足：

- 远端目录、Git 状态、AGENTS.md、README、项目配置和用户改动已重新核对。
- 前一阶段全部任务为 `完成`，或当前任务的每个跨阶段前置 ID 均有决定性证据。
- 本阶段没有前置 ID 指向未来阶段；依赖审计输出为 0 条反向边、0 个环、0 个缺失 ID。
- 影响本阶段的 `DEC-*` 已确认；建议值不能当作用户决定。
- 每条任务已识别唯一 owner、稳定服务入口、数据事实和调用方。
- 所需 schema、服务、事件、任务、媒体和页面契约存在；缺失时先补架构，不在 View/Task 临时发明。
- 所需 Git、容器、迁移、真实邮件、外部服务或生产动作授权已在当前回合取得；否则阶段不启动或明确缩小到可闭合范围。
- 页面任务已在 `prototype/page-state-matrix.md` 找到路由、身份、状态和视口。
- RED 所需的隔离 PostgreSQL、Redis、媒体目录、Mailpit、Worker 和四身份 fixture 有安全方案。

任一条件不满足时，Goal 状态应为“未启动/阻塞”，不得把大量任务先设为进行中。

## 单任务执行契约

每条 Todo 固定执行：

1. 读取任务来源章节和最新调用方，确认 `reuse/extend/extract/new/review`。
2. 写目标行为的聚焦 RED，确认失败原因确为能力缺失。
3. 建立或修改 schema/约束、policy/query/service；页面和任务不得复制领域规则。
4. 接入审计、Outbox、TaskRun、CapacityPolicy、媒体或通知时，只调用对应 owner 的稳定端口。
5. 完成 GREEN、相关回归、真实数据/文件/缓存/任务读回。
6. 页面执行角色、状态、视口、主题、键盘和焦点验证。
7. 回写状态、命令、退出码、通过数、证据位置、未执行项和风险，然后再开始下一条。

任何时刻只能有一个进行中的 Todo。临时实现子步骤可以记录在会话计划中，不新增第二份永久 Todo 真值。

## Definition of Done

一条任务只有同时满足以下条件才能标记完成：

- 用户可观察目标成立，错误、取消、重试、权限和并发路径与任务卡一致。
- 数据约束、事务、锁和生命周期在真实隔离存储读回；mock 只作补充。
- 管理员写动作与 AuditEntry 同成败；业务事件与聚合事务同成败。
- 后台任务通过 TaskRun 契约验证首成、重复、并发、重试、终败和租约释放。
- 容量、IP、账户、角色和对象权限均在可信服务端入口重判。
- 页面覆盖本矩阵要求的状态、390/1440 和适用的 768、三主题及无障碍路径。
- 任务卡列出的验证命令在当前修改后重新运行并记录退出码。
- 未获得授权的生产或 Git 动作明确列为未执行，不能作为完成证据。

阶段完成还必须满足：阶段内全部任务完成；阶段退出门禁通过；需求追踪和页面矩阵无漂移；没有依赖未来阶段的验收项。

## 跨域基础拆分

为避免阶段循环，以下能力分为基础和集成：

| 基础任务 | 提前提供 | 后续集成任务 |
| --- | --- | --- |
| `OBS-001` | Notification/Receipt/dedupe 数据与投递端口 | `OBS-008` 领域模板与 Receipt 集成 |
| `OBS-006` | TaskRun、退避、租约、终败事实事件 | `OBS-009` RuntimeError、站内通知和运维邮件 |
| `OBS-007` | 同步 CapacityPolicy 和服务端门禁 | `OBS-010` 周期采样、告警和自动解除 |
| `OBS-004` | AuditEntry、安全 schema 和事务端口 | 各领域管理员命令及 P11 页面 |

基础任务不得预写未知领域模板；后续任务不得创建第二套数据表、重试器、容量判断或审计实现。

## 停止条件

- 依赖缺失、反向阶段边或循环依赖。
- owner 重复、View/Task 形成第二业务实现中心。
- 私密内容、凭据、验证码、原 IP 或上传原文进入日志、事件、审计或截图。
- 生产/共享连接被测试使用，或迁移/清理缺少当前授权。
- 页面假成功、任务假完成、错误吞掉或缓存成为业务事实。
- 三次独立修复仍不能满足同一行为，需重新检查架构和需求。
