# 文章划词解释规划

状态：实施完成（`SE-001`～`SE-015` 全部完成）；运行时仅在 Labs 验证，未执行生产发布。

本目录记录 Kajspace 文章阅读页的“划词解释”功能。它是一个登录用户可用的文章阅读工具，不是独立聊天产品，也不改变文章正文、文章权限或全站搜索。

- [实施 Todo](./implementation-todolist.md)：按依赖顺序执行的唯一施工清单。
- [最终 Goal Prompt](./final-goal-prompt.md)：供 Goal 模式按 Todo 顺序执行和验收的完整提示词。

## 已确认的第一版范围

- 未登录用户不显示右下角入口、工具栏或选区解释按钮。
- 右下角圆形按钮展开为文章底部中央的独立胶囊工具栏；解释面板与工具栏分离，后续可加入其他阅读工具。
- 使用现有 Endpoint、AGENT、token 额度、审计、错误和调用链；新增一个纯文本解释 AGENT。
- 本期不做流式输出；等待期间显示加载动画。文档审核和题库生成继续使用原来的完整响应链路。
- 输入使用选中文字、文章标题、摘要、标签和当前一级标题；图片、链接等不解释内容会被移除。
- 默认选区上限 1000 字，超出截断但继续调用，并在回复中说明原始字数与实际处理字数。
- 用户级限制由“管理后台 > 内容与互动”配置：每日 50 次、每分钟 5 次、历史最多 30 条，均可调整。
- 历史按账户隔离，所有文章共用一个 `localStorage` 列表；每条记录显示文章 ID，停止状态也保留。
- 每篇文章首次使用单独询问授权；个人设置中的自动接受开关开启后跳过后续文章询问。
- 只有 AGENT 请求异常才显示重试；限额、授权、空选区和安全拒绝不显示重试。

## 明确非目标

- 本期不实现 SSE、ReadableStream、增量 token 或打字机效果。
- 不把解释历史保存到服务端，不建立可检索的用户问答档案。
- 不执行选区内的代码、链接、图片、外部资源或任何工具调用。
- 不把整篇文章正文发送给模型。
- 不创建第二套 Endpoint、token 额度、通知、Markdown 渲染或任务重试体系。

本目录不授权 Git 提交/推送、生产迁移、部署、服务重启、真实模型外呼或生产数据修改；执行 Todo 时仍以用户当前回合授权为准。
