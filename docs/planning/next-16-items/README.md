## 需求范围

1. 修复作者文章列表中删除按钮单独掉到第二行的问题。
2. 重新设计文章编辑器的标签选择触发器，使其与相邻控件尺寸一致。
3. 将标签选择弹窗改成可搜索的紧凑复选网格。
4. 允许为每个分区配置默认文章封面。
5. 在首页文章区增加只刷新当前列表数据的按钮。
6. 隐藏首页侧边导航的视觉滚动条，并按内容边界提供上下移动按钮。
7. 允许有子节点的父级导航成为无链接的纯分组节点。
8. 允许后台配置父级导航默认展开或折叠，公开页默认折叠。
9. 本地化“找工作”参考能力，提供公开页面以及来源和岗位后台管理。
10. 在管理文章列表中以弹窗查看当前内容和历代发布版本。
11. 修复站点设置中 Logo 控件拉伸整体布局的问题。
12. 友情链接去除 Logo 要求，并改为紧凑列表加新建/编辑弹窗。
13. 允许后台配置首页 Hero 图片或视频。
14. 为手机文章页增加右下角常驻的快捷操作展开按钮。
15. 新文章首次点击“终稿审查”时先执行一次完整草稿保存，再进入审查。
16. 将文章导入提升到新建入口，与 Markdown、富文本创建模式三选一。
