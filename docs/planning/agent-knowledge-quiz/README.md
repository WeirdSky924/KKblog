## 原始六项需求

1. 在管理后台第 7 大类中提供可复用 AGENT 配置，管理员可以配置 `BASE URL` 和 `MODEL`。
2. 每个 AGENT 只维护一份当前有效的 Markdown Prompt，并可编辑后供其他模块组装使用。
3. 具有附件权限的用户可从指定的右上角浮窗入口上传 Markdown 知识文档；文档先由审核 AGENT 判断安全性和知识文档有效性，通过后进入文档库。
4. 使用另一个预配置 AGENT 从已通过的文档生成题库；题型支持单选、多选、判断和简答，并以 Switch 选择。题库对所有人可见，生成时自动产生标签并优先复用已有标签。
5. 提供默认关闭、可由管理员开启的只读外部题库 API，包括题库列表和指定题库详情；站内题库列表也支持筛选和搜索。
6. 在顶部工作机会入口旁增加仅登录用户可见的答题入口。用户可选择题库、时间限制和抽题数量开始作答，并管理按题库归组的错题本和答题记录。

## 规划结论

- 新增两个稳定 owner：`apps/agents` 独占模型端点、AGENT、Prompt 版本和调用记录；管理员可维护多个 Endpoint，每个 AGENT 选择一个 Endpoint，多个 AGENT 可以复用同一端点。`apps/learning` 独占知识文档、审核、题库、题目、答题、错题本和只读 API。
- `administration`、页面模板和 Celery Task 只编排 owner 的公开 query/service，不保存平行业务事实。
- 知识文档上传复用 `media` 的字节探测、暂存、绑定和清理能力，并直接复用现有账户 `attachment_upload_enabled` 作为最终权限；不新建平行权限字段。
- Prompt 和模型输出都是不可信输入。审核与生成必须经过确定性格式校验、Markdown 安全渲染和固定 JSON Schema；AGENT 不能替代文件校验、权限或服务端状态机。
- Endpoint 按 LangChain 的连接模型收敛为 Provider、Model、可选 Base URL 和 API Key；API Key 支持服务器密钥别名或管理员直接录入，后者只以加密密文保存且不回显。上下文、输出、token 配额、超时和并发仍是应用级运行保护，不是 Provider 连接参数。
- Endpoint 的上下文窗口、单次输出上限、单业务运行 token 预算、请求超时和并发上限全部由管理员显式配置；系统不按模型名猜测，连通性检查也不回写这些值，运行时固化配置快照。
- Endpoint 默认/范围依次为：上下文 `131072` / `4096–2000000`，单次输出 `8192` / `256–131072`，单业务运行 `500000` / `10000–5000000` token，请求超时 `120` / `10–600` 秒，并发 `1` / `1–5`；这些只是新建默认值，管理员可逐 Endpoint 修改，服务端执行硬范围和交叉校验。
- 首版 Provider 支持 GPT、Claude、DeepSeek；公网 Endpoint 仅允许 HTTPS，本机或内网端点必须先进入服务器 allowlist，登记后才允许 HTTP。
- Endpoint、Model、AGENT、Prompt 和外部题库 API 开关都只由管理员配置；有附件权限的用户不接触这些设置或密钥，直接调用管理员启用的知识审核与题库生成能力。
- 知识审核与题库生成采用管理员配置的全站默认业务配额，并允许对单个有附件权限账户设置覆盖值；未覆盖字段继承全局配置，变更审计且只影响后续新操作。
- 默认单账户配额为每日上传 `10` 份、同时待审核/审核中 `3` 份、每日生成 `5` 次、审核与生成合计同时模型任务 `1` 个、未最终清理题库 `100` 个；每日按站点时区重置，幂等重试不重复计数。
- 单账户覆盖硬范围依次为每日上传 `1–100`、同时待处理 `1–20`、每日生成 `1–50`、同时模型任务 `1–3`、未清理题库 `1–2000`；完全禁用通过撤销附件能力完成，不用 `0` 冒充权限开关。
- 真实模型调用还必须同时受全站每日 token 上限和 Endpoint 每日 token 上限保护；调用前按最坏情况原子预留，成功完成后按可靠实际用量结算，失败/拒答/schema 修复失败/租约失效以 `0` 结算并仅通过通知说明安全错误码。金额只在配置价格时作为管理员估算展示，不阻断自建模型。
- 全站每日 token 默认 `5,000,000`、范围 `100,000–100,000,000`；Endpoint 默认 `2,000,000`、范围 `50,000–50,000,000`，且 Endpoint 不得高于全站。管理员可分别恢复默认上限或重置今日 token 已用量；重置不清正在运行预留、不影响账户业务次数，并以审计调整记录保留原账。
- 知识 Markdown 最大 `2 MiB`，按标题、列表和段落边界自动分块；Endpoint 配置上下文窗口和单任务总 token 预算，超预算时在模型调用前拒绝。
- 知识文档在同一账户内按保守规范化内容 SHA-256 去重：未清理的同文档引导到原记录，软删除中提示恢复，驳回/失败中提示查看或重试；不同账户可独立上传相同内容，系统不泄露跨账户重复关系。
- 每次上传都必须勾选默认未选中的版本化声明：确认有权上传并交由站点配置的模型服务处理，理解衍生题库、答案和解析会公开，并承诺不上传无权处理的隐私、机密或侵权内容；服务端逐文档保存声明版本与时间，并提供删除和申诉入口。
- 正式申诉覆盖知识文档驳回及管理员对文档/题库的强制隐藏或删除；每个对象同时只能有一条待处理申诉。文档申诉获准后重新进入完整 AGENT/确定性审核，不直接通过；管理处置由管理员显式恢复，申诉结果通知用户。
- 管理端只对管理员明确勾选的文档/题库提供批量隐藏、恢复和进入删除流程，执行前展示精确数量/状态并二次确认；不支持当前页或全部筛选结果一键处理，申诉决定和原文读取始终逐条完成。
- 原始知识文档只允许上传者和管理员查看全文，且只有上传者可以用自己的已通过文档生成题库；公开题库不提供原始 Markdown 下载。
- 管理员每次成功读取原文都写不可变访问审计；上传者可在文档详情查看访问时间和用途，但不接收实时通知、也不看到具体管理员身份。管理员审计保留具体操作者且不记录正文。
- 审核 AGENT 通过后文档自动进入已通过库，题库通过固定 schema 与业务校验后自动公开；不设置发布前人工审核，管理员可以事后隐藏、恢复或删除。
- 多选题采用严格匹配：必须选中全部正确项且没有任何错选才得分，否则为 `0` 分。简答题采用参考答案与评分要点后的用户自评；客观题显示自动得分，简答题单独显示掌握情况，自评结果决定错题本。
- 答题配置提供相互独立且默认开启的“随机题目”和“随机选项”Switch；开始后固定本次抽题、题序和选项序，刷新或跨设备续答不重新随机，用户可在每次开始前分别关闭。
- 普通答题和错题练习都允许多选当前可用题型，默认全选且至少一种；抽题数量上限按筛选后的可用题数更新，创建答题记录时服务端基于固定 revision 再校验并保存题型快照。
- 答题配置中的计时 Switch 默认关闭；开启后从 `10、20、30、60、90、120` 分钟中选择，初始为 `30` 分钟。计时是软提醒：到达阈值后提示超时但不自动提交、不锁定答案，用户仍可继续并正常手动提交；历史保留实际用时。
- 答题过程把选择题答案立即自动保存到服务器，简答输入采用防抖保存；刷新、退出或跨设备可恢复。并发设备通过响应版本拒绝静默覆盖，只有最终手动提交才判分和更新错题本。
- 错题是否“已掌握”完全由用户在错题本中手动切换；后续答对、答错或简答自评只更新练习统计，不自动隐藏或重新激活错题。错误历史永久与当前展示状态分离。
- 用户可查看和筛选自己的答题记录，并执行单条删除、批量删除、清空全部和 CSV 导出；所有批量/清空操作必须明确确认，CSV 只包含本人记录并防止表格公式注入。
- 答题记录与错题本是独立学习数据：删除单条、批量删除或清空答题记录都不重算、不删除错题，也不改变用户手动设置的掌握状态。
- 用户主动删除知识文档、题库或答题记录时统一进入 `7 天`软删除期：立即从正常入口隐藏，期间可撤销，期满后才受控清理；恢复不会解除原有管理员锁定。
- 被驳回/审核最终失败的知识文档及最终失败运行的完整失败材料自动保留 `30 天`；到期清理原始失败内容和运行细节，仅保留不含正文的状态、时间、对象 ID 与原因码，直到账户数据彻底清理。生成失败不会删除仍有效的通过文档。
- 源文档、题库和学习历史独立删除：删除源文档不影响已生成题库；删除题库会停止公开/API/新答题并在冷静期后清理本体，但既有答题记录和错题保留自包含快照供查看，不能再从已删除题库发起练习。
- 账户彻底删除时清理该账户的原始文档、失败材料、题库、本人答题记录和错题；其他用户已有学习快照继续保留但作者匿名为“已注销用户”，且不能再从已删除题库发起练习。最小安全审计不保留可识别账户信息。
- 同一份已通过文档可以生成多个相互独立的题库；初次生成和每次人工修正都创建不可变题库修订，不覆盖旧修订或历史答题。上传者和管理员均可修正，公开页读取当前修订。
- 生成时用户只选择允许的题型，不填写题数；AGENT 先提取整份文档的可考查知识点，再为每个知识点生成题目并决定题型分布。单次最大题数由管理员配置。
- 超过单卷题数上限时先合并相关知识点为综合题；仍无法完整覆盖则最多生成两卷，第一卷优先重要知识点、第二卷承接剩余内容。第二卷后仍超出的知识点允许舍弃，但结果必须明确提示覆盖数和遗漏数。
- 用户生成前填写题库基础标题和可选简介，AGENT 自动生成并优先复用标签；发布后上传者和管理员可修改这些元数据。两卷使用同一基础标题并自动追加卷号。
- 题库上传者可隐藏、重新公开和发起删除自己的题库；管理员拥有强制隐藏、恢复和删除能力。上传者不能解除管理员强制隐藏，避免绕过管理处置。
- 题库使用 `apps/learning` 自己的标签目录；AGENT 只在题库标签中优先复用，不与文章标签共享审核、删除、统计或使用计数。
- 题库事实保存为结构化 PostgreSQL 数据，并提供规范化 Markdown 投影；不把一个自由格式 Markdown 文件当成可判分的唯一事实。
- 文档审核、题库生成属于异步业务运行。事务提交后派发，使用现有 `TaskRun`、审计、通知、幂等和最终失败机制，不创建第二套队列或重试中心。
- 审核通过/驳回/系统失败和题库完整生成/部分覆盖生成/系统失败全部通过通用通知中心告知发起用户；系统级最终失败同时复用现有运维通知提醒管理员，重试不得重复发通知。
- 外部 API 是本项目首次公共 API 边界扩展，只提供版本化只读能力；全局开关默认关闭，开启后允许匿名 GET 并按 IP 限流，不开放上传、整理或生成写接口。列表只返回题库元数据，详情返回完整题目、答案和解析。
- 外部 API 首版 CORS 默认关闭并仅支持管理员维护的精确 HTTPS Origin 白名单；无 `Origin` 的服务端请求和本站同源调用正常工作。策略 owner 预留未来 `ANY_ORIGIN` 模式的扩展位置，但本轮不提供该配置、不返回 `*`。
- 外部 API 关闭时，列表与任意详情统一返回 JSON `404` 和稳定错误码 `api_disabled`，先检查开关再查询对象，并发送 `Cache-Control: no-store`，不泄露具体题库是否存在。
- 公开题库默认按首次发布时间倒序，并可切换最多已完成答题、题量从多到少或从少到多；修订、隐藏后恢复不会刷新发布时间，所有排序使用稳定次级键保证分页一致。
- 公开题库支持标签多选、题型多选、题量区间、发布时间区间和作者搜索选择；同一组内 OR、不同组间 AND。文本搜索模糊匹配标题、简介和标签，HTML 与外部 API 列表复用同一公开 query。
- 站内题库使用独立服务端 HTML 路由，外部题库使用 `/api/v1/question-banks...` JSON 路由；两者共享公开 query/projection，但 API 开关、CORS、限流和错误格式不影响站内页面。
- 外部 API 列表采用页码分页，`page_size` 默认 `20`、允许 `1–100`；响应提供总数、总页数、当前页和上一页/下一页链接，越过硬上限返回参数错误。
- 外部 API 按可信客户端 IP 执行管理员可调的分钟/每日双层限流，默认 `60 次/分钟、3000 次/天`；可配置硬范围为每分钟 `1–600`、每天 `100–100000`，且每日不小于每分钟。超限返回 JSON `429/rate_limited`、`Retry-After` 和标准额度头，修改配置需要审计。
- Redis 限流计数不可用时，外部 API fail closed 并返回 JSON `503/rate_limiter_unavailable` 与短 `Retry-After`，不查询题库；站内 HTML 不受影响，持续故障复用现有运维提醒。
- 公开题库与登录后答题是两个入口：访客可浏览公开题库；只有登录用户可创建答题会话、保存答案、写错题本和查看个人记录。
- 知识文档上传、整理和转题库都要求账户当前具备现有附件能力；答题、错题本和答题记录只要求登录，不要求作者或附件能力。
- 有附件能力的用户在右上角账户浮窗看到“知识文档”入口，点击进入独立“我的知识文档”页面完成上传、整理和转题库；浮窗本身不承载上传表单。

- 当前只确认 GPT、Claude、DeepSeek 三类 Provider；尚未选择具体 SDK、向量库或新增第三方依赖。
- 当前没有授权 Git 提交、推送、数据库迁移、真实模型调用、生产配置或部署。
- 未决问题在完成逐项问答前不得由实现者静默猜测；但与现有安全底线一致的确定性校验、权限复核和秘密脱敏不属于可取消项。
